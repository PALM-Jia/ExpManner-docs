# 引用方式

如果 ExpManner 支撑论文、报告、学位论文或发布实验，请引用项目并致谢相关贡献者。

canonical citation metadata 位于 private code repo 的 `CITATION.cff`。

## CFF 摘要

```yaml
cff-version: 1.2.0

type: software
authors:

    given-names: "Wanlong"

```

## BibTeX draft

在没有 DOI 的阶段，可以先使用：

```bibtex
@software{li2026expmanner,
  author = {Li, Wanlong},
  title = {ExpManner},
  year = {2026},
  version = {0.2},
  url = {https://github.com/PALM-Jia/ExpManner}
}
```

如果后续论文、数据集或 release package 有 DOI，应同步更新 `CITATION.cff` 和本页。
